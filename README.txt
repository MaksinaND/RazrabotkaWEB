Использование GET-параметров в ссылках. Виртуальная клавиатура.

Студент: Максина Надежда Дмитриевна
Группа: 241-353
Вариант: 13

Что реализовано:
1. При первой загрузке окно результата пустое.
2. При нажатии на кнопку с цифрой страница перезагружается.
3. Цифра добавляется к строке результата.
4. Предыдущее значение результата передается через GET-параметр store.
5. Нажатая цифра передается через GET-параметр key.
6. Общее число нажатий передается через GET-параметр count.
7. Кнопка СБРОС открывает index.php без параметров, поэтому результат и счетчик очищаются.
8. В подвале выводится общее число нажатий кнопок.

Как запустить:
php -S 127.0.0.1:8000

Затем открыть:
http://127.0.0.1:8000/index.php
